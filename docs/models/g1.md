# G1

G1 is a rigid articulated Unitree G1 model with STL link meshes attached to a
34-joint render skeleton.

## Setup

G1 downloads automatically on first use from the
[`abcamiletto/body-models`](https://huggingface.co/abcamiletto/body-models)
Hugging Face repository, which records the original GR00T-WholeBodyControl and
LeRobot provenance. To prefetch the assets:

```bash
body-models download g1
```

When passed manually, `model_path` should contain `xml/g1.xml` and
`meshes/g1/*.STL`.

## Notes

G1 does not define `skin_weights`. Use `forward_links()` for link transforms and
`forward_meshes()` for renderable meshes.
