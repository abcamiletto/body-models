# GarmentMeasurements

GarmentMeasurements is a PCA body model for garment measurements, with skinning
and skeleton taken from FBX assets.

## Setup

Preprocessed assets download on first use from
[`abcamiletto/body-models`](https://huggingface.co/abcamiletto/body-models) on
Hugging Face (SOMA-X: Apache 2.0). To prefetch:

```bash
body-models download garment-measurements
```
