# GarmentMeasurements

GarmentMeasurements is a PCA body model with FBX-derived skinning and skeleton
for garment measurements.

## Setup

Preprocessed assets download on first use from
[`abcamiletto/body-models`](https://huggingface.co/abcamiletto/body-models),
which records their SOMA-X Apache 2.0 provenance. To prefetch:

```bash
body-models download garment-measurements
```
